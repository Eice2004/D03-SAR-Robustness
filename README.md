# D03：SAR 目标识别鲁棒性研究

## 1. 项目简介

本项目是模式识别课程 D03 课题，使用 MSTAR 数据集进行十类 SAR 目标识别。

项目首先复现 A-ConvNet 基线模型，随后研究遮挡和相干斑噪声对模型识别性能的影响，并对比普通训练、遮挡增强、噪声增强和联合增强等策略。

## 2. 基线参考来源

- **论文**：Chen 等，2016，*Target Classification Using the Deep Convolutional Networks for SAR Images*
- **DOI**：10.1109/TGRS.2016.2551720
- **主要 PyTorch 参考实现**：[jangsoopark/AConvNet-pytorch](https://github.com/jangsoopark/AConvNet-pytorch)
- **固定参考版本**：`c60740d40407f68c9df71a8c0b871601d5ba849d`
- **原作者参考实现**：[fudanxu/MSTAR-AConvNet](https://github.com/fudanxu/MSTAR-AConvNet)

基线阶段优先保持参考实现的网络结构、数据处理规则与训练配置。必要的工程适配会单独记录。

## 3. 数据集

数据来源：[omae11/MSTAR-dataset](https://github.com/omae11/MSTAR-dataset)

使用 `soc_complex` 原始数据，包含幅度和相位两个通道。

| 数据划分 | 样本数量 |
|---|---:|
| 训练集 | 2747 |
| 测试集 | 2425 |
| 合计 | 5172 |

十类目标的标签映射固定为：

`2S1=0, BMP2=1, BRDM2=2, BTR60=3, BTR70=4, D7=5, T62=6, T72=7, ZIL131=8, ZSU234=9`

原始数据集和模型权重不提交到 Git 仓库。团队成员需自行配置本地数据路径，并使用一致的数据划分与类别映射。

## 训练阶段记录：A-ConvNet 基线初次训练

### 1. 实验目的

在 MSTAR 十类数据集上进行 A-ConvNet 基线模型训练，验证数据读取、模型训练、测试集评估、模型保存及训练记录功能，为后续遮挡和相干斑噪声鲁棒性实验建立基础。

本次实验计划训练 100 轮，但训练过程中出现明显异常，因此在第 38 轮后手动停止。本次结果暂不作为最终基线实验结果。

### 3. 训练过程与异常情况

本次训练前期表现正常，模型准确率逐渐提高。

- 第1轮测试准确率：51.71%。
- 第2轮测试准确率：87.42%。
- 第3轮测试准确率：93.90%。
- 第4轮测试准确率：96.99%。
- 第7轮测试准确率：97.90%。
- 第17轮测试准确率达到阶段最高值：98.97%。
- 第18～25轮测试准确率基本维持在96.91%～98.89%。

但在第26轮开始出现异常：

1. 第26轮测试准确率突然下降至40.45%，此时平均训练损失仍为0.0192。
2. 第27轮平均训练损失突然升高至2.3090，测试准确率下降至11.30%。
3. 第28～38轮平均训练损失持续在约2.296附近，测试准确率持续在约11.3%。
4. 学习率在整个异常发生期间保持0.001，尚未到达预定的第50轮衰减节点。

由于模型分类表现持续异常，在第38轮结束后手动停止训练。

### 5. 阶段性分析

从训练记录可以观察到：

- 第1～25轮，模型总体具有较好的收敛趋势，测试准确率最高达到98.97%。
- 第5轮曾出现一次准确率下降，但随后恢复，说明训练早期也存在一定波动。
- 第26轮出现明显异常，随后训练损失和测试准确率同时发生剧烈变化。
- 第27～38轮损失接近十分类均匀预测时的交叉熵水平，模型可能出现分类输出退化，但目前尚未通过预测类别分布验证这一判断。

目前不能确定异常的具体原因，不能直接将其归因于学习率、最后一个小批次或过拟合。
