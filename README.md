# D03：SAR 目标识别鲁棒性研究

## 1. 项目简介

本项目是模式识别课程 D03 课题，使用 MSTAR 数据集进行十类 SAR 目标识别。

项目首先复现 A-ConvNet 基线模型，随后研究遮挡和相干斑噪声对模型识别性能的影响，并对比普通训练、遮挡增强、噪声增强和联合增强等策略。

## 3. 数据集

数据来源：[omae11/MSTAR-dataset](https://github.com/omae11/MSTAR-dataset)

使用 `soc_complex` 原始数据，包含幅度和相位两个通道。

测试集保持原始图像数量，共2425个样本。

`2S1=0, BMP2=1, BRDM2=2, BTR60=3, BTR70=4, D7=5, T62=6, T72=7, ZIL131=8, ZSU234=9`

### 2026-11-01：尾批次损失缩放修复及100轮基线训练完成

**问题原因**

训练集共有134603个样本，批次大小为100，因此每轮包含：

- 前1346批：每批100张图像。
- 最后一批：3张图像。

原训练代码对最后3张图像仍然计算完整的平均损失，并执行一次完整的参数更新。

排查发现，初次训练中最后一个不完整批次的梯度更新存在异常，导致模型参数更新过猛，随后第四层发生完全失活。

**修复方法**

保留最后3张图像，不删除数据，通过实际批次大小调整损失权重：

```python
# 获取当前批次实际样本数量
actual_batch_size = labels.size(0)

# 计算原始平均交叉熵损失
raw_loss = criterion(outputs, labels)

# 根据批次大小计算损失缩放系数
loss_scale = actual_batch_size / BATCH_SIZE

# 缩放损失
loss = raw_loss * loss_scale

# 反向传播
optimizer.zero_grad()
loss.backward()

# 更新模型参数
optimizer.step()
```

正常批次的损失缩放系数为1，最后3张图像对应的缩放系数为0.03。

同时修改整轮平均损失的计算方式，按照实际样本数量进行加权统计。

**修复验证**

- 保留全部134603个训练样本。
- 最后3张图像仍正常参与训练。
- 完成修复后的100轮训练。
- 模型训练过程正常完成。
- 原先第四层持续失活、模型长期预测单一类别的问题没有再次出现。
- 训练损失整体下降，测试准确率保持在较高水平。
